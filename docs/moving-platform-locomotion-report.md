# 人形机器人在晃动平台上行走：研究现状与实验路线

日期：2026 年 11 月 18 日

## 结论

**在移动支撑面上走到指定相对位姿，可以做成有明确验收指标的研究项目。现有成果足以支撑建模和实验设计，可复现的证据不足以证明人形机器人已能在航行船舶甲板或日常载客地铁上自主走到任意目标并稳定停步。** 最适合本仓库的切入点是平地基准与可控运动平台之间的对照实验。先问“哪个控制器，在多大的平台运动下，仍能走到指定位置、转正并站稳”，再讨论场景部署。

本报告按证据来源区分固定地面能力、移动支撑面研究线索和真实场景部署。当前环境无法直接访问 arXiv 检索、Crossref 和 OpenAlex，因此这是一份有限来源的研究综述，不是截至报告日期的系统检索。文中未独立核实的论文实验细节和最新进展不作为成熟度判断的依据。

## 目前发展到哪里

| 研究层次 | 可用方法与现有证据 | 对本课题的意义 |
| --- | --- | --- |
| 固定支撑面上的双足控制 | ZMP 预瞄用未来落脚位置生成质心轨迹。Capture Point 用质心状态估计恢复平衡所需的落脚位置。已有真机学习控制研究展示动态全身动作及仿真到真机迁移。 | 能复用落脚、质心和全身控制的接口。固定支撑面实验没有覆盖随时间变化的支撑面运动。 |
| 受控移动支撑面 | 有一条专门的研究路线把时变支撑运动写进降阶模型，例如时变角动量线性倒立摆（ALIP）与鲁棒落脚控制。应按具体实验核对是否包括平移、旋转、未知输入、连续行走及停步。 | 可以用已知平台运动做前馈，再加入平台状态估计和落脚反馈。在动作可重复的平台上可测出控制器的有效范围。 |
| 真实运营场景 | 本次调研未核实人形机器人在真实海上平台或载客列车上完成“相对位姿导航、稳定停步、多次重复”的公开证据。 | 实验报告应明确运动范围、摩擦、状态信息来源、机器人型号和失败率。单次演示只说明该次工况下完成了任务。 |

### 海上平台与地铁有什么不同

| | 海上平台 | 地铁车厢 |
| --- | --- | --- |
| 首先要区分的对象 | 船舶或浮式平台随浪运动。固定式海上平台应按现场测量决定是否需要整体运动模型。 | 机器人在移动列车的车厢内行走。目标与车厢固连。 |
| 主要输入 | 分别研究横摇、纵摇、升沉，再加入多轴耦合。横摇和纵摇改变重力在甲板平面上的分量，升沉改变接触法向载荷。 | 起步和制动的纵向加减速、转弯的横向加速度、冲击及振动。行走难度更直接取决于加速度和加加速度（jerk），匀速直线运行本身可作为对照。 |
| 第一版实验 | 单轴横摇和升沉，改变幅值、频率和起步相位，再试多轴不规则输入。湿滑甲板作为独立摩擦变量。 | 用可重复的起步和制动脉冲，扫描峰值加速度、jerk 和持续时间，并比较加速度发生在起步、单脚支撑或停步时的结果。 |

这两个场景可以共用控制和验收代码，分别使用不同的平台运动输入。实验室的正弦信号和加速脉冲用于找出失效边界。要声称代表具体船型或线路，需要用实测时序或有出处的工程参数。

## 如何把现有仓库扩展成实验

当前基线生成平地上的落脚点及骨盆、双脚运动学轨迹。末帧等于目标是规划器的性质。移动平台实验必须用物理仿真中机器人实际测得的状态验收。

1. **在平台坐标系定义目标。** 令 `T_WP` 表示平台相对世界的位姿，`T_WB` 表示机器人骨盆相对世界的位姿。用 `T_PB = inverse(T_WP) @ T_WB` 计算骨盆相对平台的位置与姿态。目标继续用平台平面的 `(x, y, yaw)`。支撑脚在无滑移时固定在平台坐标系中，随平台一起在世界坐标中运动。
2. **建立物理仿真对照。** 用具体人形模型和具有碰撞几何的可编程平台，先验证平台静止时能走到目标并站稳。运动平台可从 MuJoCo 的 mocap body 开始，逐步写入 `mjData.mocap_pos` 和 `mjData.mocap_quat`。先用无控制物块检查移动接触是否正确传递运动，检查摩擦和时间步收敛，再用同一个机器人比较不同控制器。对需要考虑机器人反作用力的平台，使用带质量和约束的动力学模型。 [MuJoCo XML 参考](https://mujoco.readthedocs.io/en/stable/XMLreference.html#body-mocap)
3. **分阶段比较三种控制。** A 组使用同一个平地控制器和平台相对目标。B 组加入已知平台运动的前馈补偿，用于测量已知输入时的性能。C 组仅用模拟传感器估计平台运动，并用状态反馈修正步长、落脚位置和停步时机。平台平动可从重力减去平台原点加速度的等效量入手。旋转时还涉及与位置相关的欧拉和离心项，以及与相对速度相关的科里奥利项。将所有向量转换到同一坐标系后再计算。全身控制需约束足底接触和可用摩擦。
4. **把到达和停稳写成验收。** 第一版可沿用位置误差小于 10 cm、偏航误差小于 5°，并在连续 2 秒内维持误差和无跌倒条件。站稳判据还应约束平台相对速度，阈值在跑对照前固定。报告每个工况的试验次数、成功率、到达耗时、最大足底相对滑移和失败原因。记录平台相位、运动幅值、频率、加速度、jerk 和摩擦配置。对 A/B/C 使用相同起点、目标和平台时序，真值可以用于评测，只有 B 组的前馈可以直接使用平台运动真值。

第一批工况建议依次为静止台面、地铁制动单轴、海上横摇单轴、升沉与横摇组合。优先做**制动发生在最后两步时能否对准目标并停稳**。这既能和现有位姿任务直接衔接，也能避免只在巡航步态上验证控制器。

## 阅读清单

- **Kajita 等，2003，Biped Walking Pattern Generation by Using Preview Control of Zero-Moment Point。** 用于建立固定支撑面上的控制对照。阅读时标出恒高及支撑面假设，在增加升沉和倾斜后逐项检查。 [DOI](https://doi.org/10.1109/ROBOT.2003.1241826)
- **Pratt 等，2006，Capture Point: A Step toward Humanoid Push Recovery。** 从落脚恢复问题理解为何站立受扰和连续跨步是两个实验任务。 [DOI](https://doi.org/10.1109/ICHR.2006.321385)
- **移动支撑面专项检索。** 以 `dynamic rigid surfaces`、`swaying rigid surface` 和 `time-varying ALIP` 为关键词，优先核对论文的机器人平台、实际平台轨迹、传感输入、是否自由行走及重复次数。扩展词可用 `moving support surface`、`ship deck` 和 `biped locomotion`。 [时变 ALIP 检索](https://scholar.google.com/scholar?q=time-varying+ALIP+swaying+rigid+surface+bipedal+walking)
- **ASAP，2025，Aligning Simulation and Real-World Physics for Learning Agile Humanoid Whole-Body Skills。** 项目仓库公开了仿真到真机的工具和数据采集说明。适合参考机型建模和迁移流程。 [项目代码](https://github.com/LeCAR-Lab/ASAP)
